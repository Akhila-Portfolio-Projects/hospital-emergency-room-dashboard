 # Hospital-emergency-room-dashboard

 PROJECT OVERVIEW
 This project focuses on analysing hospital emergency room data using Microsoft Excel.The dashboard provides insights into patient        visits,waiting times,satisfaction scores,and department referrals.
 The main obejctive is to help understand patient flow and hospital service performance through an interactive dashboard

 ## TOOL USED
-  Microsoft Excel
-  Power query for data cleaning and trasformation
-  Pivot tables and Pivot Charts
-  Slicers for interactive filters

 ## DASHBOARD FEATURES
-  Total number of patients
-  Average patient waiting time
-  Patient satisfaction score
-  Patient distribution by age group
-  Gender ditribution
-  On-time and delayed patient attendence
-  Department referral analysis
-  Interactive month and year filters

 ## KEY INSIGHTS
 This dashboard helps identify patient attendance patterns,waiting time performance,Patient satisfaction, and the distribution of       referrals across hospital departments.
